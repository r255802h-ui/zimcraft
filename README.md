# ZimCraft

A Craft Discovery and Seller Listing Website for Harare, Zimbabwe

 1. Project Overview

ZimCraft is a student-developed web-based directory that helps tourists and local visitors discover handmade crafts and craft sellers in Harare, Zimbabwe.

The website provides information about craft sellers, including their craft types, descriptions, locations, opening hours and contact details.

 2. Project Objectives

- Help visitors discover craft sellers in Harare.
- Improve the online visibility of local craft sellers.
- Allow visitors to filter sellers by craft type.
- Provide contact and WhatsApp options for communicating with sellers.
- Allow craft sellers to submit their details for approval.

 3. Main Features

- Homepage introducing ZimCraft.
- About page explaining the project.
- Discover page displaying approved craft sellers.
- Craft-type filtering.
- Individual seller details pages.
- Seller registration form.
- Pending and approved seller registration status.
- Call and WhatsApp contact links.
- Responsive layout for mobile and desktop screens.

 4. Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- Visual Studio Code

 5. Project Folder Structure

- `index.php` – Homepage
- `about.php` – About page
- `discover.php` – Craft seller listings
- `market.php` – Individual seller details
- `register.php` – Seller registration
- `assets/` – Images, CSS and JavaScript files
- `includes/` – Database connection, header and footer files
- `database_structure.sql.sql` – SQL database file

6. How to Run the Project Locally

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Download or clone this GitHub repository.
4. Place the project folder inside the XAMPP `htdocs` folder.
5. Open phpMyAdmin using `http://localhost/phpmyadmin`.
6. Create a database named `zimcraft_db`.
7. Import the supplied SQL file into the database.
8. Configure the database connection in `includes/db.php` using your local MySQL details.
9. Open a browser and visit `http://localhost/zimcraft_project/` (use the actual folder name if different).

7. Database

The project uses MySQL to store craft seller information. Seller registrations are saved with a pending status and must be approved before appearing in the public seller listings.

8. Project Scope

ZimCraft focuses exclusively on craft sellers and craft discovery within Harare, Zimbabwe.
